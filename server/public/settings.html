Настройки сайтов

Сохраняются отдельно для каждого сайта.

Автоприглашение открывает чат с текстом из поля «Приветствие». Задержка — от 5 до 600 секунд после загрузки страницы. Один раз за сессию вкладки для каждого сайта; после ручного открытия или начала переписки повторно не показывается. В скрытой вкладке не открывается и вне рабочего времени не показывается.

Рабочее время определяет, какое сообщение увидит посетитель. Писать в чат можно всегда; график не означает, что оператор находится онлайн. Конец «24:00» означает полночь.

Три стартовые кнопки

Порядок блоков соответствует порядку кнопок. Нажатие отправляет текст посетителя. Автоответы пока не подключены.

Визуальный предпросмотр

Упрощённый макет, без соединения с чатом.

Код установки
